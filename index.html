MIDI2LUA · improved note engine

Maps the full 88-key range using Ctrl modifiers for extreme low/high notes. Required for some advanced piano games.

Reads the tempo from the MIDI file header instead of using the manual BPM value.

When enabled, uses actual note durations from the MIDI. When off, notes are short taps (better for many Roblox pianos).

Translates MIDI velocity into Alt+key dynamics if the game supports it.

Converts sustain pedal (CC64) events into Space key holds.

Uses a special numpad protocol for the "Piano Rooms" game. Only enable if you play that specific experience.
